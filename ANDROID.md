# Yiping Android

[Download Yiping-Android.apk (1.0.10)](https://github.com/Passione0901/Yiping-Releases/releases/download/android-v1.0.10/Yiping-Android.apk)

[Release page](https://github.com/Passione0901/Yiping-Releases/releases/tag/android-v1.0.10)

Android 7.1 or later / ARM64.

First installation: download the APK, open it, and confirm installation in Android. If prompted, allow installation from the browser or file manager you used.

Updates in builds with the in-app updater: tap Update in the game, allow installs from Yiping if Android asks, return and tap Update again, then confirm the Android update screen. The APK is kept in private cache and removed on the first menu startup after updating. No manual APK deletion is needed for these updates. Older builds and first installation still use the browser; existing browser downloads are not removed. Do not uninstall the game before updating.
